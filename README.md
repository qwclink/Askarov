# Инвестиционный симулятор «Расти с ВТБ»
## Инструкция по запуску
### Версия Python: 3.11
### Установка зависимостей:
#### pip install -r requirements.txt
### Команды запуска
#### python -m venv .venv
#### * Windows:
#### .venv\Scripts\activate
#### python main.py
#### * Linux:
#### source .venv/bin/activate
#### python3 main.py
